# Personal site direction

User preference, September 7, 2026: use Benji Taylor’s entire personal site as inspiration and take a design engineering approach throughout. References: https://benji.org, https://benji.org/family-values, https://benji.org/liveline, https://benji.org/annotating.

Preserve Wiel’s biography, voice, projects and identity. The reference informs the restraint and attention to behavior, not copied prose or branding.

- Start with a human introduction. Prefer specific work and direct links over positioning slogans, counters and repeated calls to action.
- Use a consistent narrow reading column, quiet navigation, restrained headings and compact lists. Let actual work carry the visual interest.
- Explain a design decision through the problem, the change and an inspectable example. Distinguish demonstrations from production behavior. Never invent outcomes.
- Treat hover, press, focus, keyboard use, touch, feedback, failure and reduced motion as part of each component. Motion should clarify an action or state.
- Use real recordings or working examples where they explain something. Avoid decorative effects that slow ordinary navigation.
- Review desktop and mobile visually, then exercise the interactions. Build success alone is not design acceptance.

Implemented in this pass: personal homepage, compact project/writing rows, shared navigation/footer, article/page rhythm, accessible email-copy feedback and plainer contact copy. Existing detailed case-study bodies and career facts retained, with the separately rewritten Starthome essay.

Validation: production build 37 routes; mobile checks at 390px for home, about, contact, experience, writing, projects, PortMind, Starthome and CLIP article; clipboard contents, success announcement/reset and reduced-motion state checked in browser. No deployment.
